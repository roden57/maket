# ماكيت Maket

نموذج كتلي ثلاثي الأبعاد لمشروع التخرج: **المركز التعليمي والتدريبي الطبي** — بغداد، باب المعظم.
قسم الهندسة المعمارية، كلية الهندسة، جامعة واسط.

🔗 الموقع: https://roden57.github.io/maket/

- رسم وتعديل الكتل، والمساقط والواجهات، واللوحات A3/A1
- تصدير PDF وRevit (IFC) وAutoCAD (DXF) وSketchUp (DAE)
- روابط مراجعة للدكاترة بدون حساب، وملاحظاتهم توصل مثبتة على الكتل
