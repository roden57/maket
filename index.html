العنوان

التحديد والتحريك
• النقر على الكتلة = تحديد (دون تحريك غير مقصود)
• بعد التحديد: اسحبها لتحريكها
• المربعات البرتقالية على الحواف: اسحبها لتمديد الجهة أو تقليصها
• المخروط الأزرق في الأعلى: اسحبه للأعلى أو الأسفل لتغيير عدد الطوابق
• Shift + نقر = تحديد أكثر من كتلة
• النقر بالزر الأيمن على الكتلة = قائمة أوامر (نسخ، تدوير، عكس، قفل، إخفاء، حذف)
الكاميرا
• في عرض 3D: السحب في الفراغ = تدوير، السحب بالزر الأيمن = تحريك، العجلة = تكبير
• وضع المسقط: مسقط حقيقي دون منظور، والسحب يحرّك اللوحة كما في أوتوكاد — الأدق للرسم
الرسم
• رسم ← اسحب على الأرض. يلتصق الرسم بالشبكة وبحواف الكتل
حماية العمل
• يُحفظ كل تصميم تلقائياً
• اقفل الفناء والكتل المكتملة لمنع تحريكها خطأً
• ↶ تراجع يلغي أي خطأ
المزايا
• أشكال جديدة: كتلة بفناء وسطي، كتلة ببوابة (ممر)، سقف جملون، سقف مائل — إعداداتها بتبويب تعديل الكتلة
• عناصر الواجهة: شبابيك، كاسرات عمودية/أفقية، مشربية (تعديل الكتلة ← الواجهة)
• توزيع البرنامج: المساحات ← توزيع البرنامج — حدّد وظيفة الكتل ثم انقر توزيع تلقائي
• إظهار محسّن: عرض ← (ملمس + ظلال ناعمة + سماء) — تُلتقط صور اللوحات بالجودة نفسها
• الملاحظات: النقر بالزر الأيمن على كتلة ← ملاحظة هنا، أو ملف ←
• المشرف: ملف ← إرسال للمشرف ← ملف مراجعة يُفتح بأي متصفح، ويعيد المشرف ملف ملاحظات يمكن استيراده
العرض والتحليل
• عرض ← نمط العرض: نموذج أبيض (كالماكيت) أو شفاف
• مقطع ← أفقي (مسقط طابق): اختر الطابق لعرض مسقطه الكتلي
• الشمس ← الرياح السائدة: أسهم الرياح الشمالية الغربية لبغداد
• عرض ← تسجيل فيديو: دوران حول المشروع أو حركة الظلال، ويُنزَّل ملف فيديو
• المساحات ← تقرير المساحات ومقارنة التصاميم، وتنزيل الجدول للإكسل
• ملف ← حفظ نسخة كاملة: ملف واحد يضم جميع التصاميم واللوحات (يُنصح بالاحتفاظ به احتياطياً)
أدوات جديدة
• التدوير الحر: بتعديل الكتلة (زاوية) أو Shift+R يدير 15°
• مضلع حر: اختر الشكل "مضلع حر" وارسم نقطة نقطة، وأغلقه بالنقر على أول نقطة أو Enter
• قص الكتلة: اسحب خطاً عبرها
• ملف ← تصدير 3D: ملف لسكتش أب (DAE) وللريفت (OBJ)
• اللوحات: عند تحديد عنصر يظهر تبويب "تنسيق اللوحة" يضم جميع أدوات التنسيق والمحاذاة
