العنوان

التحديد والتحريك
• ضغطة على الكتلة = تحديد (ما تتحرك بالغلط)
• بعد التحديد: اسحبها حتى تتحرك
• المربعات البرتقالية على الحواف: اسحبها حتى تمد أو تقلص الجهة
• المخروط الأزرق فوك: اسحبه للأعلى أو الأسفل حتى تغير الطوابق
• Shift + ضغط = تحديد أكثر من كتلة
• كلك يمين على الكتلة = قائمة أوامر (نسخ، تدوير، عكس، قفل، إخفاء، حذف)
الكاميرا
• بالـ3D: سحب بالفراغ = تدوير، كلك يمين وسحب = تحريك، العجلة = تكبير
• وضع المسقط: مسقط حقيقي بدون منظور، السحب يحرك اللوحة مثل الأوتوكاد — الأدق للرسم
الرسم
• ✏️ رسم ← اسحب على الأرض. الرسم يلتصق بالشبكة وبحواف الكتل
حماية الشغل
• كل تصميم ينحفظ تلقائياً
• اقفل الفناء والكتل اللي خلصت منها 🔒 حتى ما تتحرك بالغلط
• ↶ تراجع يرجع أي خطأ
الجديد
• أشكال جديدة: كتلة بفناء وسطي، كتلة ببوابة (ممر)، سقف جملون، سقف مائل — إعداداتها بتبويب تعديل الكتلة
• عناصر الواجهة: شبابيك، كاسرات عمودية/أفقية، مشربية (تعديل الكتلة ← الواجهة)
• توزيع البرنامج: المساحات ← 📋 توزيع البرنامج — تحدد وظيفة الكتل وتضغط ⚡ توزيع تلقائي
• إظهار محسّن: عرض ← ✨ (ملمس + ظلال ناعمة + سماء) — اللقطات للوحات تطلع بنفس الجودة
• الملاحظات: كلك يمين على كتلة ← 📌 ملاحظة هنا، أو ملف ← 📌
• المشرف: ملف ← 📤 للمشرف ← ملف مراجعة يفتح بأي متصفح، والمشرف يرجعلك ملف ملاحظات تستورده
العرض والتحليل
• عرض ← نمط العرض: موديل أبيض (مثل الماكيت) أو شفاف
• مقطع ← أفقي (مسقط طابق): تختار الطابق وتشوف مسقطه الكتلي
• الشمس ← الرياح السائدة: أسهم الرياح الشمالية الغربية لبغداد
• عرض ← تسجيل فيديو: دوران حول المشروع أو حركة الظلال، ينزل ملف فيديو
• المساحات ← تقرير المساحات ومقارنة التصاميم، وتنزيل الجدول للإكسل
• ملف ← حفظ نسخة كاملة: ملف واحد بيه كل التصاميم واللوحات (احتفظ بيه احتياط)
أدوات جديدة
• التدوير الحر: بتعديل الكتلة (زاوية) أو Shift+R يدوّر 15°
• مضلع حر: اختار الشكل "مضلع حر" وارسم نقطة نقطة، وسكّره على أول نقطة أو Enter
• ✂️ قص الكتلة: اسحب خط عبرها
• ملف ← تصدير 3D: ملف للسكتش أب (DAE) وللريفت (OBJ)
• اللوحات: من تحدد عنصر يطلع تبويب "تنسيق اللوحة" بيه كل أدوات التنسيق والمحاذاة
